# Babyphotoshop
Project Description
Baby Photoshop is a C++ image-processing application developed as part of the CS213 Object-Oriented Programming course at the Faculty of Computers and Artificial Intelligence, Cairo University.

The application allows users to load, display, and process images using different filters through a graphical user interface (GUI).

Requirements
C++ compiler.
Qt framework for the graphical user interface (GUI).
Image_Class.h
stb_image.h
stb_image_write.h
Required Qt components and dependencies.
Windows operating system.
Tools, Frameworks, and Libraries
Programming Language: C++
GUI Framework: Qt
Image Processing Interface: Image_Class.h
Image Loading Library: stb_image.h
Image Writing Library: stb_image_write.h
Code Editor: Microsoft Visual Studio
Operating System: Windows
Setup Instructions

Install and configure a compatible C++ development environment.

Install Qt and configure the required Qt components.

Place the project source files and required library header files in the appropriate directories.

Ensure that Image_Class.h, stb_image.h, and stb_image_write.h are available to the project.

Configure the project to use the required Qt dependencies.

How to Build and Run

Open the project in the configured development environment.

Build the application using the appropriate build configuration.

Run the generated application.

Load an image using the graphical user interface.

Select the desired image filter.

View the processed image and save the result.

Submission Notes

Include the required source code files, library header files, and project configuration files needed to build and run the application. Do not include executable (.exe) files in the submitted ZIP file.
